# Superseded: Insight Spellcraft

This page has been replaced by [Technique Mastery](#technique-mastery).

The old model was: meaningful events create insights, insights create technique proposals, and those proposals become spells.

That is no longer the intended design.

The current model is:

1. Learn a technique from a manual, teacher, enemy, relic, shrine, or experiment.
2. Gain proficiency by using, practicing, drilling, or studying it.
3. At mastery thresholds, choose to evolve the technique.
4. Bring references into the evolution: another technique, a manual passage, a strange book, a shrine, a memory, or written text from the player.
5. The LLM reads those references alongside player history and proposes evolved forms.
6. Deterministic tools validate mechanics before anything becomes real.
7. Shrines, statues, and altars handle deeper breakthroughs: path, element, bonuses, vows, curses, and weirdness ceiling.

Events still matter, but they are context. They are not automatic reward triggers.
